# WiiUIdent - Improving the Interface

This is a fork of [WiiuIdent](https://github.com/GaryOderNichts/WiiUIdent), a tool for the WiiU that displays technical information about the console.

## Why This Fork?

The idea is to give WiiUIdent's interface a fresh look. The functionality is perfect as it is, but I believe it can be made more visually appealing.

## Who Am I?

I'm someone who has never programmed in C++ before, so this project is a way to dive into the language while working on something practical. Until now, my experience has been with JavaScript and Python, languages I learned on my own.

I chose WiiuIdent because it seems simpler than [Koopair](https://github.com/GaryOdderNich/Koopair), another project by GaryOderNichts. My plan is to practice here first and later try to improve Koopair's interface as well.
